### Task 3: Add index.html to docs/ for GitHub Pages

**Files:**

**Step 1: Create the ReDoc viewer**

Write `docs/index.html`:

```html
<!DOCTYPE html>
<html>
<head>
  <title>Idle Chapters API</title>
  <meta charset="utf-8"/>
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <style>body { margin: 0; padding: 0; }</style>
```

**Step 3: Commit**
