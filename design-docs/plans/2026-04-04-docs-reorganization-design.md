# Documentation Reorganization

**Date:** 2026-04-04
**Status:** Approved

## Problem

Three documentation directories (`docs/`, `dev-docs/`, `design-docs/`) overlap in purpose. Plans are split between `docs/plans/` and `design-docs/plans/`. `dev-docs/` duplicates the GitHub Pages content in `docs/`.

## Decision

Dedicate `docs/` to GitHub Pages. Consolidate all internal documentation under `design-docs/`.

### Directory roles

- **`docs/`** — GitHub Pages site only. Holds `index.html` and `openapi.json`, both auto-generated by the FastAPI app on startup. Nothing else belongs here.
- **`design-docs/`** — Internal design documents: game design, implementation specs, and plans. Not published.

### Changes

1. Move `docs/plans/*` to `design-docs/plans/`
2. Delete `dev-docs/` (duplicate of `docs/`)
3. Add `index.html` to `docs/` for the ReDoc viewer
4. Add a "Documentation" section to `README.md`
5. Update stale path references in `README.md`
6. Update the project structure tree in `README.md`

## Constraints

- GitHub Pages is configured to serve from `main:/docs`
- `idle_chapters/api/server.py` writes `openapi.json` to `docs/` on startup
- `apps/web/src/lib/api.ts` references `docs/openapi.json` for types
